Project overview

An independent analysis of 152,410 Amazon Reviews '23 — Gift Cards reviews (UCSD McAuley Lab). A binary POSITIVE / NEGATIVE sentiment run on the first 100 reviews and a balanced three-class run (150 reviews) — both judged from title + text only, never the rating.

Primary-emotion analysis: LLM vs NRC

Two independent ways of assigning a primary emotion to each review — the LLM (context-based, one forced choice) and the NRC word list (isolated word associations). These are agreement numbers, not accuracy: neither method is emotion ground truth.

Exact vs tie-aware. Exact agreement requires the LLM emotion to equal the NRC selected primary; tie-aware agreement counts when the LLM emotion appears among all NRC emotions tied for the highest score. NRC uses a deterministic canonical tie-break rule, which is an implementation choice, not a ranking of emotions. Because 52 of 85 covered rows contain ties, exact agreement understates conceptual overlap with the word list.
